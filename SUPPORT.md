# Support

## Questions and usage help

For questions about how to use the library, first check:

- [README.md](README.md) for installation, setup, and configuration
- [docs/MIGRATION.md](docs/MIGRATION.md) when upgrading from a pre-1.2 version
- [docs/PUBLISHING.md](docs/PUBLISHING.md) for publishing and artifact coordinates

If your question is still unanswered, open an issue with the **Task / Improvement** template and start the title with `Question:`; a maintainer will label it. Include your platform
(Android, iOS, JVM), library version, Ktor version, and a minimal code sample.

## Bugs

If something does not behave as documented, open a **bug report** using the
[issue template](https://github.com/santimattius/ktor-persistent-cache/issues/new/choose) with a
minimal reproduction. Questions that turn out to be usage questions may be re-labeled.

## Feature requests

Open a **feature request** issue describing the problem you want to solve. See
[CONTRIBUTING.md](CONTRIBUTING.md) for how approved issues turn into pull requests.

## Security issues

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).

## Conduct concerns

See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
